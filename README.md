# WanderGenie 🌍

## AI-Powered Smart Tourism Guide

WanderGenie is a Django-based smart tourism web application that uses Generative AI to provide personalized travel guidance, tourism information, and landmark analysis.

The application integrates Google Gemini to answer tourism-related questions and analyze uploaded landmark images, helping users explore destinations with intelligent AI-powered assistance.

---

## 📌 Project Overview

Travelers often need information about destinations, tourist attractions, landmarks, and local places while planning or exploring a trip. Traditional tourism applications generally provide static information and may not offer interactive, personalized assistance.

WanderGenie addresses this by combining **Django, Python, and Generative AI** to create an interactive tourism assistant.

Users can ask tourism-related questions, receive AI-generated information and recommendations, and upload landmark images for AI-based analysis.

---

## 🎯 Objectives

- Provide intelligent and interactive tourism assistance.
- Generate personalized travel information using Generative AI.
- Help users obtain information about tourist destinations and landmarks.
- Analyze uploaded landmark images using AI.
- Provide a user-friendly web interface for tourism exploration.
- Manage users and tourism-related activities through an administrative module.
